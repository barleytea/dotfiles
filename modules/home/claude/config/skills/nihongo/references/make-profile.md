# 書き方メモを作る

ユーザーが自分の書いた文を貼って「私の書き方を覚えて」「この感じで書いて」と頼んだ時に読む。貼られた文から、自分の名前で出す文に使う「書き方メモ」を作る。

メモは2段に分ける。上の段は「書く時の考え方」で、この人が何を先に言い、相手とどう距離を取るかを書く。場面をまたいで使う。下の段は場面ごとの欄で、一人称・文末・長さ・言葉の例を書く。2段の前に、本人が自分で言ったことと直したことを書く「こだわり」の欄を置く。メモの最後には、場面ごとに名前と中身を伏せた「手本」を置く。見える特徴を写すより、どう考えて書く人かを先に読む。言葉や記号だけを写すと、考え方の合わない場面でもそのまま出て、モノマネになる。

## 作り方

1. 貼られた文を、場面ごとに分ける（友達へのLINE、家族、先生・目上へのメール、仕事、SNSの告知・投稿など）。場面は、ユーザーが添えた言葉（「これは告知」）を一番に使い、無ければ宛名・敬語の高さ・出す場所から決める。決めた場面は欄の見出しで見えるので、聞かずに分けてよい。README・仕様書・設計書のような技術文書は型と用語の決まりが強いので、貼られても材料にしない（ユーザーが頼んだ時だけ使う）。
2. 文ごとに、何を選んだかを読む。用件を先に言ったか、お礼やお詫びを入れたか、気持ちを言葉で言ったか記号で出したか、言い切ったかぼかしたか、断る時に理由を先に言ったか、相手をどう呼び、敬語をどの段にしたか。
3. 2通以上で同じ選び方が見えたら、考え方の1行にする（項目は下の「考え方の項目」）。どの場面の何通から読んだかを添える。場面が違う2通でもよい。1通だけで見えた選び方は書かない。nihongoがふだんする選び方（用件を先に言う、お礼を言う）と同じ物は書かず、違う物だけを書く。
4. 場面どうしの差を使う。友達と目上で何が変わり、何が変わらないかは、相手との距離の取り方の一番の材料になる。
5. 場面ごとの欄に、一人称、文末、長さと改行、言葉と記号の例を書く。材料のある場面の欄だけ作り、同じ人でも場面で書き方は違うので、混ぜて1つにまとめない。
   - 一人称と、です・ますか常体かは、1通でも書く。この2つは1通でも読み取れるし、目上や店に宛てた文は1通しか無いことが多い。
   - 長さと改行、言葉と記号の例（語尾、よく使う言葉、言い換えない言葉、記号と絵文字、書き出しと締め）は、2通以上に出た時だけ、どんな時に出るかと一緒に書く（「👍は了解の返事の時」「！は誘う文の時」）。「〜っす」「〜わ」のような語尾と、定型の挨拶（「何卒よろしくお願い申し上げます」など）も同じ。目上への定型は場面の判断で入るので、メモには要らない。ユーザーが「これはいつも使う」と言った物は1通でも書く。
   - 記号と絵文字は、どんな時に加えて、その場面で1通に使う量の目安も書く（「絵文字は1通に2〜3個、文末と気持ちの文に」）。量だけで書かず、どんな時と組にする。量を書かないと、使う側が少なめに抑えて、記号の多い人らしさが消える。
   - 方言（関西弁など）は、条件付きのクセではなく、文末と言葉の土台として扱う。親しい相手あての文に2通以上出ていたら、「友達あてはいつも関西弁」のように場面全体で書く。文の種類（自分の状況を話す文だけ、など）に限らない。目上の決まりはそのまま。
   - 言葉の例は「」で囲み、説明の文に溶かさない（「お疲れさまです」で始める）。溶かすと、書く時にそのまま文に入ってしまう。
6. 書いた後に点検する。メモの各行を、貼った文に無い場面（目上へのお詫び、お知らせなど）に当ててみて、失礼・作り話・モノマネになる行は消すか、条件を付ける（「友達へのLINEの時だけ」）。下の「書いてはいけない物」に当たる行も消す。2通以上に出たクセ（記号、語尾、絵文字、句点の有無、改行）が場面の項目に書けているかも確かめる。ここは抜けやすい。絵文字や記号が多い人なら、量の目安が書けているかも見る。
7. 場面ごとに手本を1〜2通選び、メモの最後に「### 手本」として置く。人名・出来事・予定・場所・数字と本人の名前は【　】に伏せ、名乗りは「【名前】です」の形で残す。連絡先は必ず伏せる。依頼で伏せ方を指定されたら、それに合わせる。1通しか無い場面の手本も置いてよい。手本は名乗り・句点の有無・改行・記号の位置といった見た目を伝えるための物で、中身と言い回しは写さない。手本に目上への崩しがあっても、メモの冒頭の決まり（相手と場面で敬語を先に決める）が勝つ。
8. メモは、ユーザーが読んで直せるように、nihongoの決まりで自然な日本語で書く。このファイルの中の言葉（欄、段、材料）は使わず、ふつうの言い方にする。見出しに句読点を付けない。
9. メモを見せ、違う所があれば直して、と1文だけ添える。3通より少ない時は元にした通数を書き、もっと貼ると精度が上がる、と1文だけ添える。

考え方は、どの場面でも本人名義の文なら使う。項目の無い場面では、相手との距離が近い場面の項目と手本を借りる（友達グループ→友達へのLINE、同僚→友達か先輩あて、保護者・社会人・事務局→先生や店長あて）。借りた時も、目上の決まり（敬語は下げない、「っす」「w」は使わない、絵文字はその場面の項目にある物だけ）は変えない。目上の項目にある絵文字や「！」は、その場面にだけ使い、ほかの目上の場面には借りない。目上の場面で距離の近い項目を借りる時は、一人称・文末・名乗りのような見た目だけを借りる。「店長と同じ感じで」のように依頼で場面を指定された時だけ、その項目の絵文字や「！」も使う。言葉と記号の例を控えめにするのは、目上・お店・外向けの告知（X、不特定の人に向けた投稿、公式のお知らせ）だけ。友達グループの中のお知らせは、友達あてと同じに書く。友達や同僚あてでは、書いてある「どんな時」に合う文に使う。モノマネは、この「どんな時」の条件で防ぐ。

## 考え方の項目

場面をまたいで当てはまり、文から読める物だけにする。nihongoがふだんする選び方と違う物だけを書く（誰でもする「用件を先に言う」は書かない）。

- 先に言うこと（用件、お礼、気持ち）
- 相手との距離の取り方（どこまで詰めるか、目上との線の引き方）
- 気持ちの出し方（言葉で言う、記号で出す、控えめ）
- 言い切り方（言い切る、ぼかす、確かさで分ける）
- お願いと断りの仕方（理由を先に言う、短くまっすぐ言う）
- 避けること（大げさな言葉、へりくだりすぎ など）

長さと改行は場面で変わるので、場面ごとの欄に置く。

## こだわりの欄

本人が自分で言ったことと、本人が直したことは、「こだわり」の欄に書く（「〜させていただきます」は使わない、前置きは書かない、短く書きたい）。貼った文から読んだだけの物は入れない。

- 1回言われただけ、1通直されただけでも書く。本人の言葉なので、2通以上の決まりは当てない。
- 場面をまたいで使い、メモの中では一番優先する。考え方や言葉の例とぶつかったら、こだわりに合わせる。
- ただし、相手と場面で決めた硬さと、作り話をしないことは超えない（「敬語は使わない」とあっても、先生へのメールでは崩さない）。
- 性格は推測しないが、本人が自分について言ったこと（「短く書きたい」）は、この欄に書いてよい。

## 書いてはいけない物

- 貼った文の中身（人名、出来事、予定、場所、数字）。手本では【　】に伏せる
- 人物像（性格、価値観、年齢、性別、仕事、人間関係）。文から確かめられず、推測すると作り話になる。考え方は「どう書くか」で書き、「どんな人か」にしない。本人が自分で言った物は「こだわり」に書く
- 1通にしか出ない語尾・口ぐせ・定型
- 回数だけで書いたクセ（「！を毎文に付ける」）
- 目上に敬語を下げる指示（店長の欄の「〜っす」）

悪いメモと、直したメモの例（どちらも架空の人で、合成）：

```
### 書く時の考え方
- 明るくて気配りができる人
- 用件を先に言う
- 毎文に「！」を付ける

### バイト先の店長へのLINE（1通をもとに）
- 文末：「〜っす」
- 言葉の例：「来週土曜のシフト」
```

この例には、性格の推測、誰でもする選び方（用件を先に言う）、回数だけで決めたクセ、1通にしか出ない語尾で店長への敬語を崩す指示、貼った文の中身（シフトの日）が入っている。直すと、次のようになる。

```
### こだわり
- 「〜させていただきます」は使わない（自分で直した）

### 書く時の考え方（LINE 3通とメール2通をもとに）
- 先に言うこと：お礼から入り、用件は2文目に書く
- 気持ちの出し方：友達には「！」で伝え、目上の人には言葉で伝える
- お願いと断り：断る時は理由を1つ先に言い、代わりの日を出す

### バイト先の店長へのLINE（1通をもとに）
- 一人称：自分
- 文末：です・ます

### 手本（名前と中身は伏せています。見た目だけ参考にし、中身と言い回しは写さないでください）

バイト先の店長へのLINE
お疲れさまです、【名前】です
【日付】のシフトですが、【理由】のため休ませてもらえないでしょうか。急ですみません。よろしくお願いします
```

## 形

メモは次の形にする。設定にそのまま貼れるよう、考え方は300字くらい、場面ごとの項目は1つ150字くらい、手本は1通100字くらいまでにする。書くことの無い行は消し、貼られた文が無い場面の項目は作らない。

```
## 私の書き方（nihongo）
自分の名前で出す文（LINE、メール、SNSなど）を書く時に読んでください。技術文書と、AIとしての返事には使いません。

- 敬語の高さは、相手と場面に合わせて先に決めてください。目上の人・お店・外向けの告知（X、不特定の人に向けた投稿、公式のお知らせ）では、このメモがあっても崩さないでください。「っす」「w」は使わず、絵文字はその場面の項目に書いてある時だけ使います。目上の項目にある絵文字や「！」は、その場面にだけ使います。ほかの目上の場面では、依頼で「〇〇と同じ感じで」と言われた時だけ使います。
- 「こだわり」と「書く時の考え方」は、どの場面でも使います。2つがぶつかった時は「こだわり」を優先してください。ただし、相手に合わせた敬語と、事実に無いことを書かない決まりは守ってください。
- 場面ごとの項目は、今の場面の物を使います。項目が無い場面では、相手との距離が近い場面の項目と手本を借りてください（友達グループなら友達へのLINE、保護者や事務局なら先生や店長あて）。目上の場面で借りる時は、一人称・文末・名乗りだけを借ります。
- 言葉と記号の例は、書いてある「どんな時」に合う文に使ってください。量は、項目に書いてある目安に合わせます。控えめにするのは、目上の人・お店・外向けの告知だけです。友達グループの中のお知らせは、友達あてと同じに書いてください。口ぐせを入れるために、頼まれていない気持ちや話を足さないでください。
- 手本は、見た目（名乗り、句点の有無、改行、記号の位置）だけを参考にしてください。中身と言い回しは写しません。
- 「〇〇の書き方で」と言われたらその項目を使い、「メモなしで」と言われたらこのメモは使いません。

### こだわり
- （自分で言ったこと、直したこと）

### 書く時の考え方（〇通をもとに）
- 先に言うこと：
- 相手との距離：
- 気持ちの出し方：
- 言い切り方：
- お願いと断り：
- 避けること：

### 友達へのLINE（〇通をもとに）
- 一人称：
- 文末：
- 長さと改行：
- 言葉と記号の例：

### 先生へのメール（1通をもとに）
- 一人称：私
- 文末：です・ます

### 手本（名前と中身は伏せています。見た目だけ参考にし、中身と言い回しは写さないでください）

友達へのLINE
（伏せた手本を1〜2通）

先生へのメール
（伏せた手本を1通）
```

1通しか無い場面の項目は、一人称と文末の2行だけになる。

## 置き場所

メモはスキルのフォルダには置かない（スキルを更新すると消えるため）。ユーザーの設定に置く。

- Claude Code：`~/.claude/CLAUDE.md`（プロジェクトだけなら、プロジェクトの `CLAUDE.md`）
- Codex・Muse：`AGENTS.md`
- Claude・ChatGPTのアプリ：設定にある、AIへの指示や好みを書く欄

ファイルを書ける環境では、書き足してよいかを1回聞き、OKなら末尾に書き足す。すでに「## 私の書き方（nihongo）」があれば、こだわりの欄は残したまま足し、考え方の段は新しい材料と合わせて書き直し、新しい場面の欄は足し、同じ場面の欄と手本は差し替える。書けない環境では、メモと置き場所を1行で返す。

## 育てる

自分の名前で出す文の下書きを、ユーザーが「僕はこう書かない」と直した時や、「こう書きたい」と言った時は、それを「こだわり」の欄の1行にして見せ、足してよいかを聞く（「了解しました」→「了解です」と直されたら、「了解は「了解です」と短く言う」）。直した例は、貼った文より確かな材料として扱う。直しから考え方を読み取れそうでも、推測になるので、こだわりの欄には本人が直した形のまま書く。
