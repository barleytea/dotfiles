# 文の組み立て・言葉の選び方

この資料の範囲：文と段落の組み立て（語順、文の長さ、文末、つなぎ方、倒置）と、言葉の選び方。句読点と表記は `orthography.md`、推敲の手順は `review.md` に置く。

## 文の組み立て
- 長い修飾を先に、短い修飾を後に置く。修飾する言葉とされる言葉、主語と述語を近づける。
- 話題は「は」、新しく出す物や起きた出来事は「が」で示す。1文に「は」を並べない（×今回は、この画面は → ○今回の画面は）。
- 分かりきった主語と代名詞を省く（私は、あなたは、彼は、それは、これらは）。
- 同じ文末が3つ続いたら、2文をつなぐか主語を入れ替える。文末の言葉だけを取り替えない。お知らせや仕様では気にしない。
- つなぐ言葉は使ってよい。くだけた文は「でも」「ただ」「なので」、硬い文は「しかし」「ただし」「そのため」。「また」「さらに」「加えて」を段落の頭に並べない。「これにより」「〜することで」を繰り返さない。
- 「これ」「それ」「上記」が離れたものを指す時は、名前で書く。会話の中で付けた仮の名前（A案、例の件）を、それを知らない人が読む文書に持ち込まない。
- 同じ物は同じ名前で呼ぶ（本スキル、同ツール、当該機能と呼び替えない）。
- 並べる時は形をそろえる（×進捗共有と、親睦を深めること → ○進捗を共有し、親睦を深める）。
- 「の」を3つ以上続けない。逆接でない「が、」で文を延ばさない。二重否定は肯定にする。
- 人がしたことは人を主語にする（反映しました）。受け身は、主体を出さない方がよい時だけ使う。
- 倒置（述語を先に出す形）は、強調したい時や、会話で言い足す時に使う（うまいね、これ）。説明文や仕事の文書で、理由なく語順を入れ替えない。

## そろいすぎの点検
書いた後に見る観察点で、書く前の決まりではない。
- 文の長さ、文末、段落の長さ、項目の組み立てが、全部同じ形にそろっていないかを見る。人の文章は、内容に合わせて長い文と短い文が混ざる。
- そろっていたら、内容に合わせて、関係の深い2文をつなぐか、詰め込んだ1文を分ける。長さを散らすこと自体を目的にしない。
- お知らせ、仕様、手順、表のように、そろっていること自体が役に立つ文書では、そろえたままにする。

## 言葉の選び方
- 相手がその場で普段使う言葉を選ぶ。
- 普段の漢語を和語にしない（確認、修正、変更、使用、終了、発生、通知、設定）。動詞を名詞にした和語（確かめ、直し、知らせ、置き場）を作らない。画面の操作は和語でよい（押す、入れる、開く）。
- 場が求めていないのに、普段の言葉を硬い漢語にしない（使う→活用する、消える→消失する）。
- 言葉の組み合わせは、普段言う形にする（期限が切れる、リスクを負う、対策を取る、影響が出る、予定を立てる）。
- カタカナ語は定着したものだけ使う。英語の言い回しを1語ずつ訳さない（端のケース→例外的な場合、真実の源→基準になる情報）。迷ったら英語に戻してみる。英語の決まり文句がそのまま出てきたら直訳。
- 中身のない言葉を、何をどうするかの動詞に替える。本質的、重要、効果的、適切、さまざま、包括的、最適化、活用、実現、向上、促進、〜を可能にする、〜が期待される、〜が求められる。削っても意味が同じなら削る。
- 気持ちの言葉と宣伝の勢いは残す（心に刺さりました、劇的に、今すぐ）。
- 「〜することができます」は「〜できます」、「〜を行う」は動詞1語にする。硬い文書の「実施します」は残す。
- 「〜において」「〜に関して」「〜における」は、「〜で」「〜について」「〜の」にする。論文や規約では残す。
- 書き言葉の文書の動詞・文の型・つなぎ方（「〜し、」と「〜して」）は `register.md` にある。

## 測った目安
古賀史健のnote、寺田寅彦の随筆、サイボウズの技術ブログを測った値：漢字は25〜31%、同じ文末は44〜72%、接続詞で始まる文は6〜13%。AIの素の文は、漢字36%、同じ文末81%、接続詞3%。数字を合わせることを目的にしない。この値は文章全体の傾向を知るための参考で、1つ1つの文章を評価したり直したりする基準には使わない。
