# 書き言葉の段

この資料の範囲：書き言葉の文書で、動詞・文の型・つなぎ方を書き言葉にそろえる決まり。名詞の漢語の扱いは `craft.md`、読点は `orthography.md` に置く。

## 使う文書
ポートフォリオ、ES、報告書、企画書、README・技術文書、会社やお店から出す文（取引先やお客様へのメール、ベンダーからの連絡）。依頼の言い方がくだけていても、書き言葉で書く。

友達あてのLINE・チャット・Slackの返事、エッセイやブログのような読み物、会話や説明の返事には使わない。そこでは今までどおり、普段の話し言葉で書く。

## 動詞
- 話し言葉の動詞を書き言葉にする：出す→表示する・提示する、止める→停止する、動く→動作する、選べる→選択できる、決める→決定する、要る→必要。
- 調べる・見る・使う・書くのように、書き言葉でも普通に使う和語は直さない。全部を漢語にしない。「〜を行いました」を続けない。
- 動詞は、主語や対象が何かで選ぶ。
  - 機械・システム：動作する、停止する、表示する、起動する
  - データ・値・設定：使用される、反映される、無視される、破棄される、読み込まれる
  - 乗り物・物：動く、止まる（×動作する）
  - 人：決める・決定する、選ぶ・選択する（硬さは文書の種類で決める）
- 物やデータに、人の動作の比喩を使わない（×学習率が捨てられていた → ○学習率が使用されていなかった、×設定を食べる → ○設定を読み込む、×画面に出ます → ○画面に表示されます）。

## 文の型の硬さ
左は話し言葉、右は書き言葉。書き言葉の文書では右を使う。

| 話し言葉 | 書き言葉 |
|---|---|
| 〜したあと | 〜したのち、〜した後 |
| 〜けど、〜だけど | 〜が、〜だが |
| 〜なので、〜から | 〜ため |
| 〜って（という意味） | 〜という |
| 〜みたいな | 〜のような |
| 〜じゃない | 〜ではない |
| ちゃんと | 適切に、正しく |
| すごく、とても | 非常に、大きく |
| 〜とか | 〜など |
| だけ | のみ（文書の型として限る時） |

## つなぎ方（「〜し、」と「〜して」）
- 別々の動作や手順を順に並べる時は「〜し、」にする（データを抽出し、比較した／部品にまとめ、130件のテストで確認しました）。動詞も書き言葉にする（×出して比べた → ○抽出し比較した）。「〜し」の後の読点は、どちらでもよい。
- 次の時は「〜して」のままにする。
  - 様子や、同時に行うやり方（座って話す、急いで帰る、歩いて渡る）
  - 原因・理由（雨が降って中止になった）。「〜し」も使えるが、迷ったら「〜して」。
  - 逆接（作って売らない）
  - 補助動詞が付く形（〜している、〜しておく、〜してみる）
- 見分け方：前の動詞を「〜しながら」に言い換えられれば「〜して」、「〜した後に」に言い換えられれば「〜し、」。ドアを開けて入る、のように続けて行う動作は、文ごとに決める。
- 「〜し、」を3つ以上続けない。3つ目からは文を分ける。

## 理由と読点
- 理由は文の後に回さず、前に置いて1文にする（×1行とサイト名だけです。長い説明は読まれないからです。 → ○長い説明は読まれずに閉じられてしまうため、1行とサイト名のみを表示します）。
- 短い主題の後に読点を打たない（×守らせたい条件は、工程や〜 → ○守らせたい条件は工程や〜、×〜という、目的の違う2人を → ○〜という目的の違う2人を）。

## 直しすぎない
- 書き言葉の段にするのは、文書の種類で決めた時だけ。直す時も、話し言葉の動詞・合わない動詞・後付けの理由のように、理由を言える所だけ直す。
- 社内のチャット・Slack・同僚あては書き言葉の段にしない。
- バスや電車の案内で「止まります」を「停止します」にしない。友達あての文に「〜し、」「表示します」を持ち込まない。
