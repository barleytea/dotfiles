# 翻訳・ローカライズ

- 原文の意味、条件、含意、話者の意図を保持する。日本語として自然な語順に組み替え、逐語訳を避ける。原文の文の数に合わせなくてよい。
- 英語の主語・代名詞は、日本語で不要なら省く。誰が行うかが重要な場合は明示する。
- 無生物主語や名詞句をそのまま移さず、自然な日本語の動詞表現にする（This lets you 〜 → これで〜できます）。ただし技術・契約文書では責任主体や因果を曖昧にしない。
- 原文にない説明、感情、強調、因果関係を追加しない。曖昧さが重要なら保持するか注記する。推量や条件の強さは原文のままにする。
- 固有名詞、製品名、API名、数値、日付、単位、否定、条件、例外を照合する。
- 定着した訳語がある用語は、その訳語を使う。英語の決まり文句を1語ずつ訳さない。
- メールや会話の訳は、日本語でその場面に使う言い回しに置き換える（sometime next week → 来週、ご都合のよいときに／a brief meeting → 少しお時間を）。訳した後、日本語のメールとして最初から書いた文に見えるかを確認する。
- 読者・媒体に応じて直訳、意訳、ローカライズの範囲を選ぶ。指定がなければ意味を守った自然なローカライズを行う。
- 訳は1つだけ出す。文体の指定が無ければ、原文の場面に合う方を選ぶ（メール、案内、技術文書は、です・ます）。常体と敬体を両方並べない。別案や解説は、頼まれた時だけ付ける。
