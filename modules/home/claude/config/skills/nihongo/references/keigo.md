# 敬語

- 相手の動作は尊敬語（いらっしゃる、ご覧になる、お〜になる）、自分側の動作は謙譲語（伺う、拝見する、お〜する、〜いたす）。逆にしない（×ご拝見ください → ○ご覧ください、×ご利用できます → ○ご利用いただけます）。
- 重ねない（×おっしゃられる → ○おっしゃる、×ご覧になられる → ○ご覧になる）。
- 「〜させていただく」は、相手の許可や恩恵がある時に使う。1通の中で何度も使わない。ただし、先生や企業宛てで本人が硬い敬語を選んでいる文は、そのまま残す。
- 社外の人に話す時、自分側の人（上司、家族）には敬語を付けない（部長の田中が申しておりました）。
- 目上や社外には、了解です→承知しました、ご苦労様です→お疲れ様です、すみません→申し訳ありません。
- 頼む時は、「お手数ですが」「恐れ入りますが」「差し支えなければ」を添えて、「〜いただけますか」「〜いただけますと幸いです」で結ぶ。目上に「〜してください」を重ねない。
- 「〜のほう」「よろしかったでしょうか」は使わない（こちらが資料です、よろしいでしょうか）。
- 丁寧さを1つの文章の中でそろえる。同僚や友達に「〜でございます」を使わない。
- メールの定型（お世話になっております、何卒よろしくお願いいたします）は飾りではなく型なので、残す。
- 敬語を直す時は、原文の丁寧さを下げない。誤りだけを直す。
