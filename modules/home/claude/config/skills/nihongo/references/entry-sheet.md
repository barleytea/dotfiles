# ES・志望動機・自己PR

- 設問が求める答えを冒頭で明確にする。
- 本人が実際に経験したこと、考えたこと、行動したことだけを書く。
- 数字、役割、工夫、結果を具体的にする。資料にない実績を補わない。
- 経験が1つも渡されていない設問（学生時代に力を入れたこと、など）は、空欄だけの骨組みを出さない。何をしたか、何に困って何をしたか、どうなったか、を短く聞く。メモ書きでよいと添える。
- 経験や職種が一部でも渡されている時は、質問だけを返さない。空欄にするのは、本人の経験と企業固有の情報の2種類に絞る。それ以外は、設問と、与えられた事実から書ける範囲で文章にして、そのまま手を入れられる下書きを出す。空欄だらけの穴埋めにしない。
- 与えられた事実に無い、本人の信念、決意、入社後の約束を作って足さない。締めの決意文も足さない。足りない所は空欄にする。
- 下書きの後に、たたき台であることと、空欄に入れる内容を一言で伝える。聞くことは2つまで。
- 本人の経験、実績、数字は作らない。
- ESやメールなどの書き言葉では「貴社」と書く。「御社」は面接などの話し言葉で使う。
- 本人が面接で自分の言葉として話せる表現にする。
- 抽象的な美辞麗句や企業理念の言い換えで文字数を埋めない。
- 字数制限は指定された数え方に合わせて確認する。「〇字以内」は超えず、上限の9割以上を目安にする。「〇字程度」は前後1割に入れる。材料が足りない所は作らずに【　】にし、空欄込みで数える。水増しはしない。
- 強みを列挙するより、経験から一貫した人物像が伝わる構成にする。
- 文体は本人のプロフィールに合わせる（`personal-profile.md`）。
