# AIっぽく読める癖

この資料の範囲：AIの文に出やすい形の索引。直し方は、行の最後に書いた資料にある。

書いた後に探す。場に合っていれば残してよい。人の文にも普通にある言い方（最後に、まさに）は癖に数えない。1つの癖だけで「AIが書いた」と決めない。

- 始め方：「結論から言うと」「重要なのは」「ポイントは」、「以下にまとめます」「次のとおりです」のような予告、「〜と思ったことはありませんか」、相手を持ち上げる文（いい質問ですね）。
- 終わり方：「参考になれば幸いです」「ぜひ試してみてください」「今後が期待されます」、段落の最後に足す意味づけ（これは〜を示しています）、決め台詞。
- 型：「XではなくY」「単なるXではない」（誤解を正す時だけ残す）、「〜だけでなく〜も」、3つにそろえた列挙、「一番大きいのは〜です」のような分裂文。
- 記号（→ `orthography.md`）：全角ダッシュ、文中のラベル（結論：）、強調のための鍵括弧、補足の丸括弧の多用、飾りの絵文字、太字の多用。値のラベル（日時：）は残す。
- 保険：「一概には言えませんが」「場合によっては」を重ねる。保険は1つまで。
- 言葉（→ `craft.md` の「言葉の選び方」）：定義していない造語（信頼の複利）、和語の造語（確かめ、直し）、技術の比喩（静かに壊れる、地味に効く）、「この学び」「現代の私たちは」。
- 足しすぎ：頼まれていない解説、別案、追加の質問、していないことの列挙。
- そろいすぎ：どの段落も同じ組み立て、どの項目も同じ長さ、どの文も同じ長さ。→ `craft.md` の「そろいすぎの点検」
- 整いすぎ：人なら省く所まで説明する、短いメールの敬語を1段上げる、エッセイで筋書きを順に説明する、直前の文を言い直してつなぐ、無難な感想でまとめる、「さて、本題です」と切り替える。

直す時は、癖の言葉だけを別の言葉に替えない。何を言いたい文かに戻って書き直す。
