# 見出し・題名・件名・キャッチコピー

短い文ほどAIの型が出やすい。まず、その場で人が実際に付けている実物の形に寄せる。

- ブログ・noteの題名：何をして、どうだったか（〜を半年続けた感想、〜してみた）。
- メールの件名：【用件】内容、日付（【ご案内】新人研修 4/10（木）10:00〜）。
- スライドのタイトル：そのページの主張の1文、または分類名。
- READMEの見出し：機能名や手順名（インストール、使い方）。
- アプリや商品のコピー：何ができるかを、普通の1文か名詞句で（写真を送るだけで在庫を登録できるアプリ）。
- 店や商品のSNS投稿のコピー：その店の人が投稿に書く明るさで書く。季節やその品物から誰でも思い浮かべる言葉（秋らしい、ほっくり、あったかい）は使ってよい。価格や期間は、全部のコピーに詰め込まず、添え書きにしてもよい。情報を並べただけの文（〜、〜までです）にしない。
- 研究の題名：分野の慣習に従う（〜における〜の検討、〜を用いた〜）。

## 使わない型
- 句点で区切った短い文を重ねる（「話すだけ。届く。つながる。」「引っ越して半年。思ったより快適」）。
- 読点で区切って言い切る、対句のような一文（「毎日の記録を、もっと気軽に」「意味はそのまま、伝わる文に」）。
- 「〜を、もっと〜に。」「あなたの〜を〜に。」「〜が、変わる。」
- 「〜とは？」「〜の秘訣」「〜のポイント」「〜の魅力」「徹底解説」「完全ガイド」。
- 「X：Yのための〜」とコロンで副題をつなぐ形。研究題名など、分野で普通に使う所は除く。
- 宣伝で使い古された、中身の分からない言葉（効く、刺さる、捗る、爆速、本気で、ガチで）。何がどう変わるかを書く。
- 「もう〜しなくていい」「〜なあなたへ」のような呼びかけ、「〜でも、〜」で意外さを出す形。

## 中身
- 依頼にない評価・体験・効果（劇的に変わる、手軽、こだわりの、誰でも）を入れない。依頼にある事実だけで作る。
- 案を複数出す時も、同じ型を並べない。1案目が説明型なら、2案目は別の形にする。案を出すのは頼まれた時だけ。
- 書いたら、その媒体で人が付けた実物と並べて浮かないか読む。広告のような言い回しになっていたら、何が分かるかを普通に言う形に戻す。
