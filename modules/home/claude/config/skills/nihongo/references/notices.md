# お知らせ・案内・お詫び・行政の文・規約

- 改まったです・ますで書く。漢語は漢語のまま使う（実施、終了、排出、対象外、進捗状況、別日）。ひらかない、口語にしない（×作業が早く終われば → ○作業が予想よりも早く終了すれば、×進み具合 → ○進捗状況）。
- 言葉はほぼ触らない。直すのは形と、中身のない語だけ。
- 日時、場所、対象、影響、問い合わせ先は1行ずつ書く。
- 「〜となります」は、言い切れるなら「〜いたします」「〜です」にする（休館日となります → 休館いたします）。
- 定型の敬語（〜でございます、〜いたします）は残す。
- お詫びは、何が起きたか、相手への影響、今後の対応の順に書く。原因が調査中なら、調査中と書く。責任や原因を推測で決めない。
- 行政の文・規約・契約は、義務、禁止、条件、例外の言葉を変えない。定型の言い回しを崩さない。
- 同じ語を1文の中で重ねない（×休館に引き続き休館するため）。
- 見出しは項目名にする（保存期間）。文や警告を詰め込まない。
- ログインや支払い、登録内容の確認をお願いする時は、メールのリンクから入らせず、公式アプリや公式サイト（ブックマーク）から確かめるよう案内する。パスワード・暗証番号・カード番号は聞かない。受け取る人が、詐欺の連絡と見分けやすくなる。
